# Project Name
vino-CTD-React

# Project Description
My React Project for Code the Dream. Simple todo list using
react to add new list items and display to webpage.

# Installation

Must clone project repo into local machine 

Will scaffold out a Vite project using the React template.
Then install all dependencies needed by running in terminal
"npm install"


# How to run development server

Once everything is installed you can run the development server with terminal using command
"npm run dev"
Then open the browser and for the url input
"http://localhost:5173"
